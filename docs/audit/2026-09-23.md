# Static audit — 2026-09-23

This is a static audit of the historical Utopia codebase prior to the Neurocognitive System cleanup.

## Strong existing primitives

- explicit directional hierarchy
- separate evidence, inference, policy, trace, and review concepts
- re-entry as a first-class object
- typed memory rather than a generic notes store
- PostgreSQL + pgvector architecture
- structured AI modules
- WHOOP ingestion
- model/retrieval audit data models
- calibration data model
- reproducible migration history

## Important gaps

### Trust boundary

The FastAPI surface does not currently implement a complete authentication and authorization boundary.

The code should be treated as local/private prototype software.

### Operator ownership

Many lookups use bare object IDs rather than enforcing ownership by operator. Nested routes also historically allowed path IDs and body IDs to disagree.

### Vector isolation

Semantic retrieval historically allowed operator scoping to be omitted in some paths.

### Inference failure semantics

Several AI modules historically convert parse failure into low-confidence fallback domain values. Future architecture should preserve failure as failure.

### Incomplete control loop

The main assessment loop currently uses evidence and execution services, but does not automatically integrate all of Direction, stored Physiology, Memory, Re-entry, and Calibration.

### Calibration

Calibration objects are persisted, but calibration does not yet automatically change later model/rule weighting.

### Audit wiring

Model-run and retrieval-run tables exist, but model invocations are not automatically written to them.

### Materialized views

Three materialized views exist, but the repository does not implement an automatic refresh mechanism.

### OAuth

OAuth/token storage models exist, but a complete encrypted OAuth lifecycle and refresh flow is not implemented. WHOOP sync currently accepts an access token directly.

### Verification

The test suite covers important core paths but does not yet cover the full bounded-context surface.

## Cleanup rule

The redesign should fix high-confidence correctness problems while preserving the repository as an honest historical artifact.

It should not retroactively claim production readiness.
